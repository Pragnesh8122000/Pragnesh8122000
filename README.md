## Selected work

### [AI Bestie](https://github.com/Pragnesh8122000/ai_bestie)

A full-stack AI companion with configurable personas, continuous text and voice conversations, and a React interface backed by an Express API.

**Engineering highlights:** SSE token streaming with heartbeat, timeout and client-disconnect handling; Gemini-to-OpenRouter fallback; layered persona prompts; Google/password authentication with HTTP-only JWT cookies; neural TTS with browser fallback; rate limiting and user-isolated data.

**Stack:** React 19 · TypeScript · Express 5 · MongoDB · Zustand · Zod · Gemini · OpenRouter · Kokoro TTS

### Vaidya Assist

A connected clinic-management system spanning a [backend](https://github.com/Pragnesh8122000/vaidya-assist-be), [doctor and staff workspace](https://github.com/Pragnesh8122000/vaidya-assist-fe), and [patient appointment portal](https://github.com/Pragnesh8122000/vaidya-assist-appointment).

**Engineering highlights:** role and permission controls; patient, doctor, appointment and prescription workflows; real-time notifications; Redis-backed rate limiting; reporting and file generation; tested React applications serving distinct user journeys over one shared system.

**Stack:** Node.js · Express · MongoDB · Redis · Socket.IO · React · TypeScript · Redux Toolkit · MUI · Jest · Vitest

### [Interactive AI Learning Platform](https://github.com/Pragnesh8122000/personal-ai-learning-platform)

A visual learning product for understanding LLMs, prompting, embeddings, RAG, tool use and production evaluation through interaction instead of static notes.

**Engineering highlights:** adaptive spaced repetition using SM-2, quizzes and progress tracking, interactive token-probability experiments, Mermaid-powered concepts, 3D visuals, motion design and a reproducible Vercel build setup.
